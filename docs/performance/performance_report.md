# CANN 分布式通信性能测试报告

## 1. 测试环境
- 平台：模拟器（PureSim 模式）
- 节点配置：单节点 8 NPU（昇腾 910B）
- 链路参数：HCCS 100 GB/s，延迟 0.001ms

## 2. 测试方法
- 使用 Google Test + 自定义基准测试框架
- 每个算法运行 1 次（含预热），测量端到端时间
- 数据规模：1KB、64KB、1MB、16MB

## 3. 测试结果

### 3.1 AllReduce 性能对比（8 ranks）

| 数据规模 | Ring (ms) | RHD (ms) | 加速比 |
|---------|-----------|----------|--------|
| 1 KB    | 0.933     | 0.690    | 1.35x  |
| 64 KB   | 1.232     | 1.073    | 1.15x  |
| 1 MB    | 7.704     | 6.932    | 1.11x  |
| 16 MB   | 100.943   | 117.275  | 0.86x  |

### 3.2 分析
- 小数据（≤1MB）：RHD 由于步数更少（6步 vs 14步），延迟更低
- 大数据（16MB）：RHD 每步通信量更大，总带宽利用率反而低于 Ring
- 结论：RHD 适合延迟敏感场景，Ring 适合带宽敏感场景

## 4. 理论性能分析
- Ring 带宽效率：(N-1)/N = 87.5%（8 ranks）
- RHD 步数优势：log2(8)=3 vs 8-1=7，步数减少 57%
- 瓶颈分析：模拟器中阻塞 recv 导致串行化，实机可能表现不同
