# 极致优化方案设计文档

## 1. 目标

在项目稳定运行的前提下，从 6 个维度做到极致优化，争取比赛最佳奖项。

## 2. 优化维度

### 2.1 拓扑感知调度
- 算法选择器根据链路类型（HCCS/ROCE）和拓扑结构自动选择最优算法
- 多节点场景使用分层算法：节点内 HCCS 快速路径 + 节点间 ROCE 聚合
- 小数据走低延迟路径，大数据走高带宽路径

### 2.2 流水线算法
- AllReducePipeline：将 Reduce-Scatter 和 AllGather 分成多个 chunk 流水线化
- 每个 chunk 独立发送/接收，同时对已到达的 chunk 执行归约
- 流水线深度可配置（默认 4 个 chunk）
- 性能预期：大数据场景吞吐量提升 20-40%

### 2.3 正确性验证增强
- 参考实现：Python/numpy 朴素算法
- 精度漂移测试：1000+ 次迭代检测累积误差
- 边界条件测试：count=1、count=nranks、count < nranks、大数据块
- 随机化测试：随机输入数据对比参考实现

### 2.4 性能分析深度
- 多维度基准测试：7 种算法 × 6 种数据量 × 3 种拓扑
- 扩展性分析：2/4/8/16 ranks 加速比曲线
- 自动生成 Markdown 性能报告
- 瓶颈分析：带宽瓶颈 vs 延迟瓶颈识别

### 2.5 Agent 能力深度
- Prompt 优化：每种算法类型的详细 Few-shot 示例
- 知识注入：拓扑特征、硬件参数、性能瓶颈模式
- 迭代改进：读取基准测试结果，自动分析并提出优化方案
- 代码审查：检查边界条件和性能问题

### 2.6 工程化完善
- Broadcast 原语：Ring Broadcast 算法
- 流量控制：Channel 层拥塞感知和速率限制
- 超时重传：FaultChannel 超时检测和自动重试
- 错误恢复：链路故障自动切换备用路径

## 3. 实施优先级

| 优先级 | 内容 | 影响维度 |
|--------|------|---------|
| 1 | 流水线算法 | 算法创新性 + 通信性能 |
| 2 | 拓扑感知调度 | 算法创新性 + 工程化 |
| 3 | Broadcast 原语 | 功能正确性 |
| 4 | 正确性验证增强 | 功能正确性 |
| 5 | 性能分析深度 | 通信性能 |
| 6 | Agent 能力深度 | Agent 专项 |
| 7 | 流量控制/超时重传 | 工程化 |

## 4. 预期收益

- **算法创新性**：流水线算法 + 拓扑感知 = 差异化竞争力
- **功能正确性**：5 种原语 + 严格验证 = 满分正确性
- **通信性能**：流水线 + 拓扑感知 = 最优性能
- **工程化水平**：流量控制 + 错误恢复 = 工程完整性
- **Agent 专项**：深度 Prompt + 迭代优化 = Agent 智能化
